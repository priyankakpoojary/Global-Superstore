# 🌍 Global Superstore Dashboard

## 📌 Project Overview

This project analyzes **Global Superstore Sales Data (2011–2014)** using **SQL, Excel, and Power BI** to uncover business insights, profitability trends, customer behavior, and market performance.

The project focuses on transforming raw business data into meaningful insights through data cleaning, analysis, visualization, and dashboard development.

---

## 🚀 Tools & Technologies Used

| Tool          | Purpose                           |
| ------------- | --------------------------------- |
| 🛢️ SQL       | Data querying & business analysis |
| 📊 Power BI   | Interactive dashboard creation    |
| 📈 Excel      | Data cleaning & preprocessing     |
| 🐍 Python     | Data analysis using Pandas        |
| 📑 PowerPoint | Business presentation & reporting |

---

## 📊 Key Business Insights

✨ Generated **$12.6M+ Revenue** across global markets
📈 Revenue grew consistently from **2011 → 2014**
💻 Technology category generated the **highest profit**
🌏 APAC became the **top-performing market**
⚠️ Furniture category suffered due to **high discounting**
🚚 Standard Class shipping dominated customer preference
